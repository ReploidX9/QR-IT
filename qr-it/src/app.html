Uses your look settings. Each code is test-scanned before it goes in the ZIP, along with an index.csv listing every file.

Why these never expire: the data is stored in the pattern itself. Many "free" generators make dynamic codes that point at their own redirect server, then switch it off when a trial ends. A static code has no server to switch off.

Every code is test-scanned in your browser as you edit, using the same kind of decoder a phone uses. Your look settings are remembered on this device only; the content you type is never stored.

Batch mode is built for asset tags, kit labels and room signs: paste a list or load a spreadsheet export and get every code in one ZIP.

Print tip: keep the quiet zone at 4 modules and test-scan before you print a batch.
